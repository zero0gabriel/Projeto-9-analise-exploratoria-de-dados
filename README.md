# Análise Exploratória de Dados (EDA) - Brasileirão

Guia prático de **Análise Exploratória de Dados (EDA)** em Python utilizando Pandas e um dataset histórico do Brasileirão[cite: 2].

## 📋 Sobre o Projeto
O notebook (`template_EDA_simples.ipynb`) aplica um roteiro analítico sobre o arquivo `Tabela_Clubes.csv`[cite: 2], cobrindo:
* Limpeza e tratamento de dados.
* Análise estatística descritiva (mínimos, máximos e médias).
* Respostas a perguntas de domínio (como idade média, valor total dos times e saldo de gols).
